# Security Notes

This project applies Django/DRF security primitives, server-side authorization, ORM parameterization, CSRF protection, throttling, secure cookie/HSTS settings, transactional bidding, signed payment webhooks, and restricted audit access.

It is not a guarantee of absolute security. Before production, perform dependency scanning, source review, SAST/DAST, penetration testing, concurrency/load testing, secret rotation exercises, backup restore tests, and provider-specific payment/security validation.

Report suspected vulnerabilities privately to the project security owner rather than publishing exploit details.
